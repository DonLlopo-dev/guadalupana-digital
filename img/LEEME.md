# Fotos del sitio

Sube aquí tus fotos con **exactamente** estos nombres y aparecerán solas en la página
(mientras no existan, la página muestra un marco con el nombre del archivo).

| Archivo | Dónde aparece | Formato sugerido |
|---|---|---|
| `servicio-misa.jpg` | Servicio: intención de misa | horizontal 16:9 |
| `servicio-rosas.jpg` | Servicio: rosas | horizontal 16:9 |
| `servicio-veladora.jpg` | Servicio: veladora | horizontal 16:9 |
| `guadalupe-101.jpg` | Sección Guadalupe 101 | vertical 3:4 |
| `tepeyac-1.jpg` … `tepeyac-4.jpg` | Galería "Desde el Tepeyac" | horizontal 4:3 |

Usa fotos propias o con derechos de uso. Tamaño recomendado: máximo 1600 px de ancho y menos de 400 KB cada una.
